# Customer Shopping Behavior Analysis

## #Project Overview

This project analyzes customer shopping behavior using Python, MySQL, and Power BI to uncover purchasing patterns, customer segments, and revenue insights. The dataset was cleaned, transformed, stored in a relational database, and analyzed using SQL before being visualized in an interactive Power BI dashboard.

The objective of this project is to demonstrate an end-to-end data analytics workflow, from raw data preprocessing to business intelligence reporting.

---

## #Objectives

* Clean and preprocess raw customer shopping data.
* Perform feature engineering to improve analysis.
* Store processed data in a MySQL database.
* Answer business questions using SQL.
* Build an interactive Power BI dashboard for visualization.
* Generate actionable insights into customer behavior.

## #Project Workflow

### 1. Data Preprocessing (Python)

The dataset was cleaned and transformed using Pandas.

Key preprocessing steps include:

* Handling missing values in **Review Rating** using median values within each product category.
* Renaming columns using **snake_case** for consistency.
* Creating customer **Age Groups** using quartile-based segmentation.
* Converting purchase frequency into numerical values (days).
* Removing duplicate information by dropping redundant columns.
* Exporting the cleaned dataset into a MySQL database.

---

### 2. Database Management (MySQL)

The cleaned dataset was imported into MySQL for analytical querying.

Several SQL queries were written to answer business questions related to customer purchasing behavior.

---

### 3. Business Analysis

The project answers questions such as:

* Revenue generated by male vs. female customers.
* Customers who used discounts but spent above average.
* Top-rated products based on customer reviews.
* Average purchase amount by shipping method.
* Spending comparison between subscribed and non-subscribed customers.
* Products with the highest percentage of discounted purchases.
* Customer segmentation into New, Returning, and Loyal customers.
* Most purchased products within each category.
* Relationship between repeat buyers and subscription status.
* Revenue contribution across different age groups.
